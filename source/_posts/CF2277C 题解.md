## 题意简述

给一棵以 $1$ 为起点、要到达 $n$ 的树，以及 $m$ 次操作。每次操作先加一条边 $(1,v_i)$，再从新形成的环上删一条边，使图仍然是一棵树。

求经过所有操作后，$1$ 到 $n$ 的距离最大是多少。

> tag：树、贪心

> 难度：CF 1300

## 思考

先把原树以 $1$ 为根，求出每个点的深度和父节点。原本 $1$ 到 $n$ 的距离就是 `dep[n] - 1`，这是答案的初始值，因为每次都可以直接删掉刚加上的边，让树保持不变。

### 一次操作能带来什么变化

加入边 $(1,x)$ 后，环由新边和树上 $1$ 到 $x$ 的路径组成。若删除新边，操作没有效果；若删除原树边，才可能改变 $1$ 到 $n$ 的路径。

最终的 $1$ 到 $n$ 简单路径至多使用一条新增边：所有新增边都连着 $1$，而简单路径不能重复经过 $1$。因此，其他操作都可以不改变树，答案只需考虑某个操作点 $x$ 单独带来的最大收益。

设 $p$ 是 $x$ 和 $n$ 的最近公共祖先。若 $x$ 不在原来的 $1$ 到 $n$ 路径上，且 $p\ne 1$，那么 $1$ 到 $p$ 的路径上存在一条边，同时位于 $1\to x$ 和 $1\to n$ 两条路径上。执行 $(1,x)$ 并删掉这条公共路径上的边后，新的 $1\to n$ 路径可以从新增边走到 $x$，再沿原树走到 $n$。

新路径长度为：

$$

1+\operatorname{dist}(x,n)

=1+\operatorname{dep}[x]+\operatorname{dep}[n]-2\operatorname{dep}[p]

$$

若 $x$ 在原主路径上，或者 $p=1$，则无法用这种方式绕行增加距离，不必考虑。

### 不用每次求 LCA

所有查询的终点都是 $n$，可以先标记原树上 $1\to n$ 的主路径。再遍历整棵树，为每个不在主路径上的点记录它从主路径分出的节点 `shang[x]`。这个点就是 $x$ 与 $n$ 的 LCA，所以查询时直接使用 `shang[x]` 即可，不需要倍增求 LCA。

遍历时，沿主路径向下走就更新分叉点；进入不在主路径上的子树后，分叉点保持不变。

### 算法步骤

1. 迭代遍历树，求 `par` 和 `dep`。

2. 从 $n$ 沿父节点回溯到 $1$，标记主路径，初始答案设为 `dep[n] - 1`。

3. 再次迭代遍历，求每个非主路径点的 `shang[x]`。

4. 读入每个操作点 $x$，若它不在主路径上且 `shang[x] != 1`，用上面的公式更新答案。

## 复杂度

每个点和每次操作都只处理常数次，时间复杂度 $O(n+m)$，空间复杂度 $O(n)$。

## 代码

```cpp

#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

const int N = 5e5 + 7;

vector<int> e[N];

struct Node

{

int u, fa, top;

};

void solve()

{

int n, m;

cin >> n >> m;

for (int i = 1; i <= n; i++)

e[i].clear();

for (int i = 1; i < n; i++)

{

int u, v;

cin >> u >> v;

e[u].push_back(v);

e[v].push_back(u);

}

vector<int> par(n + 1), dep(n + 1);

par[1] = 0;

dep[1] = 1;

stack<int> st;

st.push(1);

while (!st.empty())

{

int u = st.top();

st.pop();

for (int v : e[u])

{

if (v == par[u])

continue;

par[v] = u;

dep[v] = dep[u] + 1;

st.push(v);

}

}

vector<bool> onPath(n + 1, false);

for (int u = n; u != 0; u = par[u])

{

onPath[u] = true;

if (u == 1)

break;

}

ll ans = dep[n] - 1;

vector<int> shang(n + 1);

stack<Node> st2;

st2.push({1, 0, 1});

while (!st2.empty())

{

auto [u, fa, top] = st2.top();

st2.pop();

if (!onPath[u])

shang[u] = top;

for (int v : e[u])

{

if (v == fa)

continue;

if (onPath[v])

st2.push({v, u, v});

else

st2.push({v, u, top});

}

}

for (int i = 0; i < m; i++)

{

int x;

cin >> x;

if (!onPath[x] && shang[x] != 1)

{

int p = shang[x];

ll candidate = 1LL + dep[x] + dep[n] - 2LL * dep[p];

ans = max(ans, candidate);

}

}

cout << ans << '\n';

}

int main()

{

ios::sync_with_stdio(false);

cin.tie(nullptr);

int t;

cin >> t;

while (t--)

solve();

return 0;

}

```
