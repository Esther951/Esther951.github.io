## 思路

把每个点映射到单位圆上，问题变成「在圆上取半圆最多覆盖多少点」。

排序用上半平面判断 + 叉积，不用 `atan2`，避免精度问题：

```cpp
bool upper(Point p) { return p.y > 0 || (p.y == 0 && p.x > 0); }
bool cmp(Point a, Point b) {
    bool ua = upper(a), ub = upper(b);
    if (ua != ub) return ua > ub;
    return cross(a, b) > 0;
}
```

窗口合法性同样用叉积判断：`cross(a, b) > 0` 表示从 `a` 逆时针转到 `b` 小于 180°。
数组复制一遍后双指针扫过去即可。
