## 题意简述

有 $n$ 堆金币，第 $i$ 堆有 $a_i$ 枚，初始有一个整数 $x$。每次可以选一堆金币，令 $g=\gcd(a_i,x)$，拿走 $g$ 枚，并将 $x$ 改成 $g$。当找不到满足 $\gcd(a_i,x)>1$ 的堆时停止。

求最多能拿走多少枚金币。

> tag：贪心、数论

> 难度：CF 1200

## 思考

关键观察：每次操作后，新的 $x$ 都是旧 $x$ 的因数。因此，整个过程中 $x$ 的质因数只会不断减少，不会增加。

### 上界：答案一定对应某个质因数

假设最后一次操作后得到的 $x$ 含有质因数 $p$。由于每次新的 $x$ 都整除上一次的 $x$，所以每次拿走的金币数都含有 $p$。

每次被拿金币的那一堆，原本的金币数也必须含有 $p$。因此，对任意质因数 $p\mid x_{\text{初始}}$，能拿走的总数都不会超过：

$$

S_p=\sum_{p\mid a_i}a_i

$$

所以答案不超过所有初始质因数对应的 $S_p$ 的最大值。

### 下界：固定质因数可以拿完整堆

反过来，任取一个质因数 $p\mid x_{\text{初始}}$。只处理那些 $a_i$ 能被 $p$ 整除的堆。

每次选中一堆后，当前的 $x$ 和这堆金币数都含有 $p$，所以它们的最大公因数也含有 $p$。重复选择这一堆，直到它被拿空，再处理下一堆。整个过程中 $x$ 始终含有 $p$，因此所有能被 $p$ 整除的堆都可以全部拿走。

于是 $S_p$ 可以达到。结合上界，答案就是：

$$

\max_{p\mid x_{\text{初始}},\ p\text{ 为质数}}\sum_{p\mid a_i}a_i

$$

若 $x=1$，没有质因数，无法进行任何操作，答案为 $0$。

## 算法步骤

1. 分解 $x$，得到它的所有不同质因数。

2. 对每个质因数 $p$，累加所有能被 $p$ 整除的 $a_i$。

3. 输出这些和的最大值。

分解时只需试除到 $\sqrt{x}$，并在找到因子后将其幂次除尽，避免重复记录。

## 复杂度

设 $\omega(x)$ 为 $x$ 的不同质因数个数。时间复杂度为 $O(\sqrt{x}+n\omega(x))$，空间复杂度为 $O(n+\omega(x))$。

## 代码

```cpp

#include <bits/stdc++.h>

using namespace std;

using ll = long long;

void solve()

{

int n, x;

cin >> n >> x;

vector<int> a(n);

for (int &v : a) cin >> v;

vector<int> primes;

int y = x;

for (int p = 2; 1LL * p * p <= y; ++p)

{

if (y % p == 0)

{

primes.push_back(p);

while (y % p == 0)

y /= p;

}

}

if (y > 1)

primes.push_back(y);

ll ans = 0;

for (int p : primes)

{

ll sum = 0;

for (int v : a)

{

if (v % p == 0)

sum += v;

}

ans = max(ans, sum);

}

cout << ans << '\n';

}

int main()

{

ios::sync_with_stdio(false);

cin.tie(nullptr);

int t;

cin >> t;

while (t--)

solve();

return 0;

}
```
